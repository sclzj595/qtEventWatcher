# Qt 卡顿排查辅助器 PRD 01：项目概述与产品定位

## 1. 项目名称
Qt 卡顿排查辅助器（Qt Event Watcher）

## 2. 产品定位
面向 Qt Widgets 桌面程序及后续嵌入式 Linux 场景的轻量级性能排查组件。通过应用层事件分发拦截、MetaCall 专项监测、事件周期统计和 QSS 资源监测，在不依赖专业 Profiler 的情况下发现 UI 卡顿来源。

## 3. 核心目标
- 定位主线程慢事件。
- 定位跨线程信号槽 MetaCall 阻塞。
- 发现高频事件造成的持续性主线程压力。
- 监测外部 QSS 加载、setStyleSheet 和样式更新行为。
- 保持低侵入、低开销、可动态启停。
- 支持 Qt 5.14.2、5.15.2、6.5.3，MSVC 与 MinGW。

## 4. 产品边界
本项目只面向 QWidget / Qt Core / Qt GUI 事件与 QSS 相关问题，不实现 QML、Qt Quick、GPU 渲染帧分析。

## 5. 核心原则
稳定性优先、异常采集优先、正常路径轻量化、业务代码最小改动、不修改 Qt 源码。
