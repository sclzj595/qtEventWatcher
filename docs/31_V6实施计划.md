# PRD 31：V6 实施计划 —— 代码质量证明线

> 状态：规划定稿（2026-09-30）。主题：**从"实测驱动"到"证明驱动"**——功能已闭环（V1~V5.1），本版本不为功能加码，把质量资产补成可对外证明的形态：纯逻辑单元测试、静态分析门禁、Sanitizer 实证。
> 同期决策：跨栈卡顿检测（Electron/任意桌面程序）立项为**产品线 B（Scout）**，仅 Roadmap 占位，不进 V6（V7 候选，外部探针 T1 窗口冻结 + T1b CPU 启发 + T2 CDP 适配三层，复用 aggregator/HTML 数据面）。

## 1. 背景

- 质量审计结论（2026-09-30）：功能维度无缺口，质量短板为——①纯逻辑类零直接断言（TestEventWatcher 仅集成冒烟）；②无静态分析；③Sanitizer 从未跑过；④外部输入健壮性未测。
- 涉危面集中在**纯函数**：解析族（parseFields/parseFrames/hydrateRecord）、决策器（AlarmSuppressor 状态机）、配置解析（WatchConfig env/INI）、门控（kindOf 前缀分发）。这些正是外部 review 者最先看的代码。

## 2. Phase Q1：单元测试基建 + 纯逻辑覆盖（P0）

### 基建
- `tests/unit/` 新目录；自写轻量断言头 `QEWT.h`（CHECK/CHECK_EQ 宏 + 失败计数 + main 汇总，风格与 TestEventWatcher 一致），**不引入 QtTest/单一框架依赖**。
- 独立 target `UnitTests`（静态链 QtEventWatcherCore），四矩阵编译纳入 run_regression.ps1 的 build 阶段（可选 `-SkipUnitTests`）。

### 目标与用例清单
| 目标 | 依赖面 | 用例 |
|---|---|---|
| WatchRecordStore::parseFields/parseFrames/hydrateRecord（公有静态） | 纯 std::string/vector | 空串/多空格/无等号 token/值含空格截断/重复 key；坏帧跳过/单帧/多帧/0x 十六进制；QSS op 提取/slow event 全字段/stack 拆帧/hydrate 幂等（重复调用先清空） |
| AlarmSuppressor（三参 evaluate 合成时钟，V4 B1 已预留） | 纯（mutex+map） | 窗口首条必出/窗口内静默累计/窗口过期冲刷 suppressed=N/不同 key 隔离/startMs=-1 哨兵（t=0 边界）/windowMs<=0 回退缺省 |
| kindOf 门控（经行为级路径：makeSink + spdlog logger 打日志 → snapshot 断言 kind/条数） | spdlog | 四前缀命中/非告警日志排除/静默条 DEBUG 也采集/环形 4096 覆盖 |
| WatchConfig env 解析层 | QCoreApplication（测试 main 内创建） | 纯十进制（"15"）/0x 前缀拒绝（落默认）/非法串/越界钳制/位掩码展开 |

### 验收
四矩阵 UnitTests 编译+全过；既有 quick 回归 4/4 PASS 无回归。

## 3. Phase Q2：静态分析清零（P1）

- 编译警告 /W3→**/W4** 全仓清零（MSVC 四矩阵中的两个 MSVC 项；MinGW 同步 -Wall -Wextra 清零）。
- cppcheck 一轮全仓清零，固化 `scripts/static-check.ps1`（--enable=warning,performance,portability，排除 build*/third_party）。
- clang-tidy 暂缓（MSVC 下 compile_commands 成本高，收益边际）。

## 4. Phase Q3：ASan 实证（P1）

- 新建 build-asan（MSVC /fsanitize=address，仅 Qt5 MSVC 单矩阵），跑 TestEventWatcher 全模式 + Benchmark off/slow。
- 泄漏/越界/UAF 清零；发现即修。一次性实证，不进常规回归矩阵（运行成本高）。

## 5. Phase Q4：集成补强（P2，时间允许）

- TestEventWatcher 补 uplink/health 行为级断言（起 aggregator 子进程或内嵌 QLocalServer 模拟对端，断言 pushed/reconnects 语义），替代当前手工 e2e。
- aggregator main.cpp 的 op 分发/rebuildStructured 若需单测，最小重构抽 AggregationSession——仅在 Q1~Q3 全绿后考虑。

## 6. 执行顺序与文档

Q1 → Q2 → Q3 →（Q4 择机）。每 Phase 四矩阵编译验证，实施记录落 docs/21 §13；完成后 README 质量徽章（tests/static-analysis）补挂。

## 7. 风险

- kindOf 经 sink 行为级测试依赖单例状态（WatchRecordStore::instance），用例间用 kind 计数隔离而非清空——环形无 clear 语义，不做破坏性 API。
- /W4 可能暴露 spdlog/Qt 头的外部警告——只对本仓库源码文件收紧（按 target include 目录区分，不用 /external 全局开关，保持简单）。
