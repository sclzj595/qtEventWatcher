## 2. 各阶段交付明细

### 2.1 A1 慢事件调用栈采集

- **能力**：慢事件 / 慢 MetaCall 告警时采集调用栈（`RtlCaptureStackBackTrace` ≤32 帧 → 模块基址/模块名/偏移快照），归因从事件级到函数级。
- **设计取向**：仅告警路径付费，热路径零成本；采集侧**零 dbghelp 依赖**（SymInitialize 首次可达百 ms 级，禁止进告警路径），输出 `模块名!偏移`，符号解析放导出侧或离线工具。
- **出口**：告警日志行尾 `stack=` 字段；WatchRecordStore 结构化 frames → CSV 第 17 列 / JSON frames 数组。
- **实测**：MinGW5 GUI 压测 396 条告警 **100% 携带 stack**，MetaCall 栈呈现 queued 槽执行链、Event 栈呈现完整消息分发链（qwindows→USER32→Qt5Core→demo）。

### 2.2 A2 告警风暴抑制

- **问题**：高频卡顿时同类 WARN 可达 100 条/s，日志 IO 在卡顿窗口内放大负载。
- **语义**：同类告警 1s 窗口首条必出 + 后续静默累计 + 窗口关闭懒冲刷 `suppressed=N` 汇总（零定时器）；**仅抑制日志，记录全量保留**。
- **级别路由**：logger 门 = min(用户级别, debug)，文件/控制台 sink = 用户级，RecordSink = debug 全量，WatchLogCapture = warn（UI 只见 WARN+）。CMake 须 PUBLIC 定义 `SPDLOG_ACTIVE_LEVEL=SPDLOG_LEVEL_DEBUG`（默认 INFO 会编译期剥离 DEBUG 宏）。
- **实测**：MetaCall 风暴文件告警 **333→33 条（10× 去重）**+ 36 条 storm 汇总，文件 0 条 DEBUG 泄漏，存储全量逐条。

### 2.3 B1 冻结观测与看门狗

- **能力**：ANR 模式冻结检测——主线程心跳 QTimer + 看门狗常驻线程 100ms 轮询，停滞超阈值即三态告警 **started（附取证快照）→ ongoing（1s 节流）→ recovered（含总时长）**。恢复判定以"心跳前进"为准；freezeStartMs 取最后一次心跳 → totalMs 精确。
- **取证快照**：notify 入口记录"正在处理的事件"（receiver 类名 + 事件类型），冻结时即知"卡在哪个事件"。快照绑定心跳线程（构造线程），非心跳线程零开销早退。
- **配置**：WatchFreeze bit4（WatchAll=31）；FreezeThresholdMs=2000 / HeartbeatIntervalMs=250，环境变量 + INI + IPC 三通道热更新。
- **GUI 实测**（--autofreeze 3000）：`started stalledMs=2063 receiver=QSingleShotTimer type=1 inProgress=true → ongoing → recovered totalMs=3269`——取证精准命中 msleep 载体事件。
- **两个关键踩坑**（已固化到记忆/文档）：① 基类 QApplication 构造/析构期即派发事件进 notify，成员必须判空（否则 0xC0000005）；② notify 是全进程虚函数，worker 线程事件同样经过，单例快照必须线程绑定。

### 2.4 C1 SQLite 持久化导出

- **语义**：DataExporter 后缀分发——`.db/.sqlite/.sqlite3` → QSQLITE 全量重建（事务 + 失败删半成品）；**四表**：meta / records（18 列）/ frames（+索引，lastInsertId 关联）/ statistics（复用 periodToJson 行化，零重复计算）。
- **类型化**：costMs/thresholdMs→REAL、depth/signalId→INTEGER、其余 TEXT——SQL 可回放查询。
- **部署踩坑**：app-dir 存在 windeployqt 的 Qt5Core.dll 时插件路径随其重定位，而 windeployqt 不部署 sqldrivers → QSQLITE 不可用；修复为 CMake `qew_deploy_sql_plugins()` POST_BUILD 部署（copy 前须 make_directory）。
- **验证**：冒烟注入 → 导出 → 回读 rec=4 / frames=2 / typedCost=OK / meta=OK。

### 2.5 C2 自包含 HTML 报告

- **形态**：纯 HTML+CSS、**零 JS、零外部依赖、离线可开**，UTF-8 无 BOM，动态文本全量 escapeHtml 防注入。
- **五章节**：概览（counts 同 JSON 口径 + 监控配置快照）、诊断结论（DiagnosticSummarizer 四规则 + INFO/WARNING/CRITICAL 徽标）、统计 TOP（跨周期合并，累计耗时 TOP-10 + Exclusive 累计列）、冻结时间线（三态区分）、明细记录（最近 200 条折叠、时间倒序）。
- **入口**：GUI"HTML 报告"按钮 + Ctrl+Shift+H + Toast。

### 2.6 D1 终态性能基准回归

Harness 扩展：A2 后 tight-loop 场景实测的是被抑制路径（与 V2 基线不同语义），新增 `alert-first` 场景（间隔 1.1s > 抑制窗口）补齐完整告警对照。四矩阵终态数据（对照 V2 基线）：

| 开销线 | V2 基线 | V3 终态 | 结论 |
|---|---:|---:|---|
| ① 覆写固定开销 | 131~140ns | **160~182ns** | +25~45ns（B1 看门狗进 notify），帧预算 0.001% |
| ② 正常路径增量 | 657~854ns | 610~952ns | 同量级（含看门狗写入 + 线程注册表） |
| ④ spy 回调增量 | +31~62ns/emit | +34~58ns | 持平（发射路径未被 V3 触碰） |
| ③ 风暴抑制路径 | （V2 全告警 27~37µs） | **15.6~18.6µs** | **减半——A2 达成设计目标** |
| ③ 完整告警路径 | 27~37µs | 110~153µs | 3.4×：主增量 = A1 栈采集格式化 + 懒冲刷双行落盘，仅阈值命中事件付费 |

**终态结论**：开销线量级关系 ①≪②≪④≪③ 维持；常驻与正常路径回归可忽略（+45ns 内）；风暴路径减半；"首条告警"以 3.4× 换取函数级归因——监控器仍不成为新的卡顿来源。

### 2.7 D2 公共 API 收紧

- 审计发现：QtEventWatcherCore 的 include 目录 7 个模块目录全 PUBLIC，内部头（EventWatchdog/AlarmSuppressor/IpcConfigServer 等）事实公有化。
- 收紧：**PUBLIC 收窄为 application / config / logging / qss / include**（接入面：CusApplication.h、WatchConfig.h、WatchLogger.h、QssStyleWatcher.h、WatchEventInfo.h）；**event / ipc / runtime 转 PRIVATE**；tests / benchmark / basic_demo 白盒 include 显式声明。
- 收紧即时收益：第一轮全量重建唯一漏网即 demo 对内部头 `MetaCallFilter.h` 的依赖——白盒清单从此显式、可审计，库内部重构不再波及 consumer 编译面。
- 已知边界（候选）：CusApplication.h 按值持有 WatchConfig 使 config 目录连带公共（彻底隐藏需 unique_ptr 改造）；install 产物公共头补齐待 install 模型启用。

## 4. 工程质量资产

- **四矩阵编译纪律**：每阶段 Qt 5.15.2/6.5.3 × MSVC/MinGW 全量编译 + 冒烟回归，MinGW 矩阵暴露并修复了 GCC 8.1 标准库 bug（std::filesystem→QDir::mkpath）与 API 宏映射（K32*）等编译器差异。
- **GUI 级实测手段**：MinGW5 demo 压测（watchFun 位掩码 + SlowMetaCall=1ms）、--autofreeze 冻结注入、优雅关闭保证 spdlog 落盘。
- **踩坑知识库**（已固化项目记忆，择要）：
  - QApplication 子类 notify() 是全进程共用虚函数，构造/析构期即被调用，成员判空必须先行；
  - 多线程事件派发污染单例取证快照——快照必须绑定心跳线程；
  - SPDLOG_ACTIVE_LEVEL 编译期门控；环境变量纯十进制解析；
  - windeployqt 不部署 sqldrivers + 可重定位 Core 的插件路径重定位；copy_if_different 不自建目录；
  - .moc 报"本地函数定义非法"时根因在宿主 .cpp 的作用域（else-if 绑定错位）而非 moc 生成物；
  - 解析 Qt 私有 API 必须走官方 public inline 访问器；sender 生命周期必须在发射时刻快照。

## 5. 遗留与后续路线

**搁置项**（环境/决策依赖）：
- C3 多进程聚合——按决策暂缓；
- D3 Linux 验证——无环境，可移植性已在代码层保证（非 Windows 空实现 + 门控）；
- Qt 5.14.2 运行时适配——V1.3 起搁置。

**候选优化**（有数据支撑，按需启动）：
1. 栈采集移到抑制判定之后（完整告警路径 3.4× 的主要削减项；代价 = 被抑制事件记录失去 frames，违背全量记录语义）；
2. CusApplication 改 unique_ptr 持有 WatchConfig，彻底隐藏 config 目录；
3. install 模型启用时补齐公共头安装面；
4. 抑制窗口（1s 编译期常量）实测后评估是否入 WatchConfig。

**V4 方向建议**（从 D 线候选池延续）：CI 基准自动化（benchmark 进 CI 防回归）、Linux 验证（环境具备后单独立项）、多进程聚合（跨进程数据消费场景明确时启动）。
