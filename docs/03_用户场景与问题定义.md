# Qt 卡顿排查辅助器 PRD 03：用户场景与问题定义

## 1. 目标用户
- Qt Widgets 开发人员。
- PC 客户端性能测试人员。
- 嵌入式 Qt 应用开发人员。
- 稳定性与压力测试人员。

## 2. 典型问题
### 场景 A：点击按钮后界面短暂冻结
怀疑槽函数、事件处理或同步计算阻塞主线程。工具需要直接给出慢事件及接收对象。

### 场景 B：后台线程更新 UI 后偶发卡顿
怀疑 queued connection / MetaCall 密集投递。工具需要识别慢 MetaCall，并输出发送者、接收者和 signalId。

### 场景 C：窗口切换后明显卡顿
怀疑大量控件样式重新计算或 QSS 更新。工具需要提供 QSS 相关调用与资源数据。

### 场景 D：压力测试期间无明显单次卡顿，但整体越来越卡
怀疑高频 Timer、Paint、UpdateRequest 或 MetaCall。周期统计用于发现单位时间内高频事件。

## 3. 预期结果
开发人员拿到日志后，应能从“发生了卡顿”进一步缩小到“哪个事件 / 哪个对象 / 哪条 MetaCall 链路 / 哪次样式更新”。
