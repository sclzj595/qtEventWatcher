# Qt 卡顿排查辅助器 PRD 16：构建测试与验收标准

## 1. 构建矩阵

必须至少验证：

| Qt | Compiler |
|---|---|
| 5.14.2 | MSVC |
| 5.14.2 | MinGW |
| 5.15.2 | MSVC |
| 5.15.2 | MinGW |
| 6.5.3 | MSVC |
| 6.5.3 | MinGW |

## 2. 功能测试
- 慢 MousePress / Timer / Paint 等事件可以发现。
- 高频 Timer 可以被周期统计发现。
- queued signal 形成 MetaCall 时能够进入专项监控。
- 已知 Qt 版本的 MetaCall 解析测试通过。
- QSS 外部文件 IO 与 setStyleSheet 埋点数据正确。
- Watch_Fun 各 bit 组合正确。
- 日志文件正常滚动。

## 3. 稳定性测试
- 事件嵌套。
- QObject 析构。
- 大量高频事件。
- 连续 setStyleSheet。
- 长时间运行。
- 日志目录不存在。
- 日志文件无法写入。
- MetaCall 无法解析。

## 4. 验收原则
任何监控功能失败都不能影响被测程序核心业务运行。
