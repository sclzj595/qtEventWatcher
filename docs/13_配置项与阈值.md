# Qt 卡顿排查辅助器 PRD 13：配置项与阈值

## 1. 建议配置

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| Watch_Fun | 0 | 功能位 |
| SlowEventThresholdMs | 30 | 慢事件阈值 |
| SlowMetaCallThresholdMs | 30 | MetaCall 阈值 |
| EventStatPeriodMs | 1000 | 统计周期 |
| EventCountThreshold | 100 | 高频次数阈值 |
| EventTotalCostThresholdMs | 100 | 累计耗时阈值 |
| EventAvgCostThresholdMs | 0（关闭） | 周期平均耗时阈值（对应 PRD 07 平均耗时告警） |
| QssLoadThresholdMs | 50 | QSS 总加载阈值 |
| SetStyleSheetThresholdMs | 30 | 样式更新阈值 |
| QssFrequentCountThreshold | 10 | 高频样式刷新次数 |
| ConfigPollIntervalMs | 60000 | 配置刷新周期 |

## 2. 配置来源优先级
建议：
1. 程序运行时 setter。
2. 配置文件。
3. 环境变量。
4. 编译期默认值。

## 3. 配置原则
所有阈值集中管理，不允许散落 magic number。

## 4. 热更新口径（定稿）
- INI 是唯一热更新源，按 ConfigPollIntervalMs 轮询修改时间并原子 reload（PRD 11 §5）；环境变量仅启动时读取。
- 优先级：Runtime Setter > INI > Environment > Default；V1 不做 Override 层。
- 单项非法回退单项默认值，不影响其他配置项与监控运行。
