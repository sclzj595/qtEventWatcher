# Qt 卡顿排查辅助器 PRD 14：安全性与低开销设计

## 1. 低开销
- 关闭功能时快速 return。
- 正常事件不输出日志。
- 计时使用轻量高精度计时器。
- 不在 notify 中执行文件 IO。
- 不在 notify 中执行复杂字符串格式化，除非命中告警。
- 周期统计避免频繁动态内存分配。

## 2. 生命周期
- Receiver 只在需要时读取信息。
- MetaCall 私有结构解析必须先验证指针与版本。
- QPointer 可用于 QObject 生命周期观察，但不能把 QPointer 当作任意内存结构安全校验机制。

## 3. notify 安全
监控逻辑失败时必须优先保证原始 `QGuiApplication::notify()` 正常执行。

## 4. 日志安全
日志失败、磁盘不可写等情况不得导致 Qt 主线程崩溃。

## 5. 关键原则
监控器自身不能成为卡顿来源，更不能因为监控导致被测程序行为发生明显改变。
