# Qt 卡顿排查辅助器 PRD 07：事件周期统计

## 1. 目标
发现单次事件不一定很慢、但高频出现后持续消耗主线程的情况。

## 2. 默认周期
1000ms。

## 3. 每类事件统计
- Count：事件触发次数。
- TotalCost：累计处理时间。
- AverageCost：平均处理时间。
- MaxCost：周期内最大单次耗时。

## 4. 告警条件
支持：
- 次数阈值。
- 总耗时阈值。
- 平均耗时阈值。

## 5. 周期边界
统计周期结束后生成汇总并清空当前周期数据，进入下一周期。

## 6. 线程安全
统计数据主要发生于 GUI 线程时应优先采用低开销结构；后台配置读取不得阻塞 notify。

## 7. 统计口径（定稿）
- 周期统计**默认基于 Inclusive Cost**：统计目标是“一个 Event 在主线程上整体造成多少处理压力”，与慢事件判断口径一致，不因嵌套事件破坏既有统计定义。
- 嵌套事件不得被重复计费为多个独立主线程执行阶段。
- Exclusive 聚合（`totalExclusiveCostMs`，处理责任归因）留作后续能力，V1 不强制。
