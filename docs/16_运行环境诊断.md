# Qt 卡顿排查辅助器 PRD 16：运行环境诊断（Runtime Diagnostics）

## 1. 定位
辅助诊断能力，不改变 Event / MetaCall / Statistics / QSS 四条核心监控链路：
- 不占用 Watch_Fun 任何 bit。
- 不进入 notify() 热路径，不做周期性高频扫描。
- 默认仅在打开运行环境页面时刷新；完整依赖扫描、PE/ELF 分析仅在用户主动请求时执行。

解决两类问题：
1. 程序在这台机器上为什么运行异常：DLL 缺失 / 版本异常、Platform Plugin 部署失败、编译器 / ABI 不匹配、构建依赖与运行时加载不一致。
2. 卡顿问题发生时，程序实际运行在什么 Qt / 编译器 / DLL 环境，保证诊断结果可复现。

## 2. 模块组成

```text
RuntimeDiagnostics
├── RuntimeInfo          应用 / Qt / 编译器环境信息
├── ModuleEnumerator     当前进程运行时模块枚举
├── DependencyAnalyzer   构建依赖与运行时依赖分析
└── QtEnvironment        Qt 版本 / ABI / Plugin 状态

平台隔离：
Windows ─ WindowsModuleEnumerator + PeDependencyAnalyzer（第一阶段）
Linux   ─ /proc/<pid>/maps + ELF DT_NEEDED（后续）
```

## 3. 采集内容

| 分组 | 字段 |
|---|---|
| Application | 名称、可执行文件路径、PID、架构、构建配置（Debug/Release） |
| Qt | 版本（Major/Minor/Patch）、Build ABI、平台名 |
| Compiler | 编译器类型（MSVC/MinGW）、版本、目标架构 |

## 4. 运行时模块与状态诊断
- 枚举当前进程加载模块：Module Name / Full Path / Base Address / Module Size。
- 状态判定：✓ Loaded、! Path Unexpected、! Version Mismatch、! Missing。
- 重点关注：Qt DLL、Qt Platform / Image Plugin、MSVC Runtime（VCRUNTIME140 / MSVCP140）、第三方运行时 DLL。

## 5. 构建依赖与运行时依赖分离
两者不得简单等同，必须分开呈现：
- Build Dependencies：Qt5::Core / Qt5::Gui / Qt5::Widgets / spdlog / QtEventWatcherCore。
- Runtime Dependencies：Qt5Core.dll / Qt5Gui.dll / Qt5Widgets.dll / qwindows.dll / VCRUNTIME140.dll / MSVCP140.dll。

## 6. 依赖树（Windows 第一阶段）
- 读取 PE Import Directory，获得直接 DLL Import，形成基础依赖树。
- 识别缺失 DLL 并显示其完整路径。
- 缺失项展开显示：搜索位置（应用目录 / PATH / Qt Runtime）与可能原因（未部署 / 架构不匹配 / 版本不匹配）。
- 不要求复制专业 Dependencies 工具的全部 PE 分析能力。

## 7. Qt Plugin 诊断
覆盖 platforms/ imageformats/ styles/ iconengines/：
- 显示 Plugin 名、路径、状态（Loaded）。
- qwindows.dll 缺失时直接对应典型错误："no Qt platform plugin could be initialized"。

## 8. 稳定性要求
Runtime Diagnostics 自身异常不得影响主程序与四个监控器：
- DLL 分析失败仅输出 `DependencyAnalyzer failed`（依赖分析失败），不允许崩溃。
- DLL 枚举、依赖扫描信息不得因每一个 Event 重复输出。

## 9. 平台支持矩阵

| 功能 | Windows | Linux |
|---|---|---|
| Event / MetaCall / Statistics / QSS 监控 | ✓ | ✓ |
| Qt Environment | ✓ | ✓ |
| Runtime Modules | ✓ | 后续 |
| DLL Dependency / PE 分析 | ✓ | — |
| SO Dependency（ELF） | 后续 | 后续 |
| Qt Plugin Check | ✓ | ✓ |

Qt 版本：5.14.2 / 5.15.2 / 6.5.3；编译器：MSVC / MinGW；Windows x64 优先。
