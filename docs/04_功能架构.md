# Qt 卡顿排查辅助器 PRD 04：功能架构

## 1. 总体结构

```text
Application
    |
CusApplication::notify()
    |
+-----------------------+
| Event Watch Core      |
|  - Slow Event         |
|  - MetaCall Watch     |
|  - Event Statistics   |
+-----------------------+
    |
+-----------------------+
| QssStyleWatcher       |
|  - QSS Load           |
|  - Style Update       |
|  - QSS Statistics     |
+-----------------------+
    |
WatchConfig ---- spdlog
```

## 2. 模块职责
- `CusApplication`：全局事件入口。
- `EventWatcher`：单事件耗时判断。
- `MetaCallWatcher`：MetaCall 专项分析。
- `EventStatistics`：周期聚合统计。
- `QssStyleWatcher`：QSS 相关监测。
- `WatchConfig`：环境变量与运行配置。
- `WatchLogger`：spdlog 统一封装。

## 3. 依赖原则
监控模块依赖 Qt，不反向依赖业务模块；日志通过统一接口输出，业务不得直接依赖监控内部实现。
