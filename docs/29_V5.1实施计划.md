## 1. 版本定位与决策

V4 D3 诚实降级时留档的依据：HtmlReporter 签名绑定单进程三件套（`WatchRecordStore::instance()` 快照 + `WatchConfig*` + `EventStatistics*`），与 aggregator 跨进程数据模型（`map<pid, Session>`，QJsonObject 记录）不匹配——"为尚无真实用户的场景重构导出接口，收益低于成本"。

现在用户明确要求补齐该段，**重构口径决策**：

| 方案 | 内容 | 取舍 |
|---|---|---|
| A. 扩展 HtmlReporter | 抽象数据源接口 / 增加重载接受记录数组 | 公共 API 膨胀（违背 V4 D2 收紧方向）；诊断四规则依赖 WatchConfig/EventStatistics，跨进程无语义，抽接口后必然留空壳 |
| **B. 独立 AggregationReporter（选定）** | examples/aggregator 局部新增渲染模块，直接消费 Session 数据模型 | 零 src 公共面改动；escapeHtml/CSS 少量复制（~40 行，可接受）；生命周期与 aggregator 同仓同发，无版本 skew |

**V5.1 主题：多进程聚合 HTML 报告**——把 V4 D 线 + V5 B 的聚合数据面（records + health）接上"人工阅读"出口，与 HtmlReporter（单进程）分工互补。

## 3. Phase A：AggregationReporter 模块

- **文件**：`examples/aggregator/AggregationReporter.h/.cpp`（新，aggregator CMakeLists 追加源文件）；
- **接口**：`bool exportHtml(const QString &filePath, const std::map<qint64, Session> &sessions, const QString &serverName, QString *error)`——Session 需前置声明问题：直接在 AggregationReporter.h 定义输入结构（从 main.cpp 移出 Session 定义到共享头，main.cpp include 之），避免交叉依赖；
- **渲染形态**：与 HtmlReporter 同款自包含静态 HTML（纯 HTML+CSS，零 JS 零依赖，escapeHtml 防注入），章节：
  1. **概览**：generatedAt / server 名 / sessions 数 / received 合计 / dropped 合计 / 跨进程分 kind 计数（SlowEvent/MetaCall/Qss/Freeze 徽标着色）；
  2. **进程健康度表**（V5 B health 的可视化脸面）：每 pid 一行——records（环形现存）/ received / dropped / health{pushed, dropped, reconnects, lastSeq}（无 health 时 muted 标注"未上行"）；
  3. **TOP 接收者**：跨进程合并 SlowEvent 记录，按 receiver 聚合 costMs（解析 fields 中的字符串数值），输出 count / 累计 costMs / 最大 costMs TOP-10——替代单进程版的"统计 TOP"（EventStatistics 跨进程不可合并，此处以告警记录实测值为口径，诚实标注差异）;
  4. **冻结时间线**：kind=Freeze 记录跨进程合并表（新增 pid 列），started/ongoing/recovered 三态语义与 HtmlReporter 一致；
  5. **明细记录**：跨进程合并最近 200 条（<details> 折叠，时间倒序），列 = HtmlReporter 8 列 + pid 列；
- **明确不做**（克制 + 诚实）：诊断四规则（DiagnosticSummarizer 依赖 WatchConfig/EventStatistics，跨进程无语义）；stack 帧展示（HtmlReporter 单进程版明细表同样不含，保持口径一致）；周期统计 percentile（跨周期本就不可合并）。

## 4. Phase B：验收与文档收口

- **e2e**：aggregator `--duration 14 --html report.html` + 2×basic_demo（`--stress` 风暴 + `--autofreeze` 冻结源，uplink 环境变量同 V4 范式）→ 断言：
  1. HTML 无 `<script`（零 JS 纪律）；
  2. 五章节齐全；进程健康度表 2 行且 health pushed 与退出汇总 stdout 一致；
  3. TOP 接收者含 `receiver=StressGen` 行（fields 消费侧重建链路走通的行为级证明）；
  4. 冻结时间线含 pid 列且行数与 demo 冻结告警数一致；
- **回归**：四矩阵 build + smoke 全绿；全量 quick 回归无 DRIFT（报告为纯冷路径导出，热路径零改动）；既有 e2e（`--out` JSON 导出）复跑不受影响；
- **文档**：docs/21 增 §12 V5.1 实施记录；docs/28 §1 阶段表 C 线改"✅ 兑现（V5.1）" + §5 遗留清单同步；docs/26 §6 映射表 HTML 段行更新；记忆补条目。

## 5. 风险清单

| 风险 | 缓解 |
|---|---|
| Session 定义从 main.cpp 移出引发聚合器编译面变化 | 纯移动 + include，无逻辑改动；四矩阵编译守门 |
| QJsonObject fields 数组解析脆弱（[[k,v]..] 形状） | 形状由本仓 rebuildStructured 生成，同仓同发；解析失败静默跳过（协议容错纪律） |
| 大记录量导出卡顿（4096×N 条全表拼接） | 明细限 200 条折叠；TOP/时间线为全量遍历但仅字符串拼接，冷路径可接受 |
| 中文文件名 / 路径 | QFile + QString::fromLocal8Bit 既有范式，无新增 |
