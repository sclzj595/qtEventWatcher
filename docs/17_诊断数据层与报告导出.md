# Qt 卡顿排查辅助器 PRD 17：诊断数据层与报告导出

## 1. 定位
为展示层（PRD 18/19）与报告导出提供统一诊断数据模型。约束：
- 不为 UI 过早重构已完成的 EventWatcher / EventStatistics / MetaCallWatcher / QssStyleWatcher。
- 先保持各监控模块独立，QSS 完成后再统一设计诊断展示层。

## 2. DiagnosticRecord

```cpp
struct DiagnosticRecord
{
    enum class Type { Event, MetaCall, Statistics, Qss };

    Type type;
    qint64 timestampMs;
    int severity;          // Info / Warning / Error
    double costMs;
    double thresholdMs;

    // 按类型挂载明细（variant 或子结构）
    EventRecord event;         // type / name / receiver / objectName
    MetaCallRecord metaCall;   // sender / signal / signalId / receiver
    StatisticsRecord stat;     // event / count / totalCost / period
    QssRecord qss;             // operation / file或object / count
};
```

## 3. 分类别字段规范

### 3.1 慢事件
Event Type、事件名、Receiver 类名、Receiver objectName、耗时、阈值、发生时间。

### 3.2 MetaCall
Sender 类名、Sender objectName、Signal 签名、SignalId、Receiver 类名、Receiver objectName、耗时、阈值。

- `invokeMethod(Qt::QueuedConnection)` 形态可能出现 `sender="" signalId=-1`，属合法 MetaCall，不得判为监控异常。
- 数据生命周期：MetaCallParser 产出**值快照**（signalId / signalSignature / senderClassName / senderObjectName / receiverClassName / receiverObjectName），不向下游长期暴露私有事件裸指针。
- Sender 属 best-effort 信息：无法安全解析时降级为 `sender="" signal="" signalId=-1`，仍允许输出慢 MetaCall。
- signalId → signalSignature 必须使用 `QMetaObjectPrivate::signal()` 机制，禁止用 `QMetaObject::method(signalId)` 代替。

### 3.3 周期统计
Event Type、事件名、Count、TotalCost、Period、次数阈值、总耗时阈值。

### 3.4 QSS
Operation（load / setStyleSheet）、File 或 Object、耗时、阈值、周期调用次数。

## 4. 最近异常缓冲
- Demo 展示层维护有限容量（建议最近 100 条），支持按时间排序、类型筛选、清空、查看详情。
- 缓冲属于 Demo 展示层，不进入 Core 高频监控路径；Core 只提供轻量事件通知 / 数据接口，不为 UI 保存无限历史。

## 5. 诊断报告导出

### 5.1 格式与内容
支持 .txt / .json，内容至少包括：Application、Qt Environment、Compiler、Architecture、Runtime Modules、Qt Plugins、Dependency Information、Monitor Configuration、Recent Slow Events、Recent MetaCalls、Event Statistics、QSS Diagnostics。
