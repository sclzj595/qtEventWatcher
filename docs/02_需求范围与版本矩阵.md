# Qt 卡顿排查辅助器 PRD 02：需求范围与版本矩阵

## 1. 支持版本

| 维度 | 支持范围 |
|---|---|
| Qt | 5.14.2 / 5.15.2 / 6.5.3 |
| GUI | QtWidgets、QtGui、QtCore |
| 编译器 | MSVC、MinGW |
| 平台 | Windows 优先；架构预留 Linux 嵌入式 |
| C++ | 以 Qt 对应工具链可稳定支持的语言标准为准 |
| 日志 | spdlog |

## 2. 功能范围
1. 全局 QEvent 耗时监控。
2. QEvent::MetaCall 专项监控。
3. 周期事件频次与累计耗时统计。
4. 外部 QSS 加载监控。
5. setStyleSheet 调用监控能力。
6. QSS 高频刷新统计。
7. Watch_Fun 动态功能开关。
8. spdlog 日志落盘及滚动。
9. 运行环境诊断（RuntimeInfo / 模块枚举 / 依赖树，辅助能力，不占 Watch_Fun 位）。
10. 诊断数据层、最近异常缓冲与诊断报告导出（.txt / .json）。

## 3. 明确不做
- QML / Qt Quick。
- QQuickWindow 帧分析。
- GPU 硬件级性能分析。
- 修改 Qt 源码。
- 注入式系统级 Profiler。
- 依赖商业性能分析工具。
